# Glossary of the website (French · English · Arabic)

Every term shown on the website (`frontend/`) and in the texts generated by `src/site_text.py` follows this table, in the three languages of the site. Arabic is Modern Standard Arabic.

Conventions:
- **Digits.** Arabic pages use Latin digits (`0-9`, decimal point `.`, thousands separator `,`), like the charts and tables, so that a number reads the same in the three languages. French uses a decimal comma and a narrow no-break space between thousands (`4 233,5`); English uses `4,233.5`.
- **Formulas in Arabic.** Formulas and signed numbers (`HR = 0.47`, `p < 0.001`, `−3`, `14–46`) are wrapped in Unicode isolates (LRI … PDI) so that they read left to right inside right-to-left text.
- **Codes.** Dataset codes (`Policy-Based`, `Dictator-Created`…) never appear in running text: they are replaced by the labels below. Variable names in `code` style (`v2x_polyarchy`, `Gov_Non code`) are kept as they are.
- **Review.** ⚑ marks Arabic terms that should be checked by a native speaker with a background in statistics or political science: they either have several competing translations in Arabic, or are rarely translated at all.
